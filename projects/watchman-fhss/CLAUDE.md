
## Terminology (project swap list)

Use the field's own terms; do not coin. Known drift in this repo's articles and the fix:

| Drift | Use instead |
| --- | --- |
| ladder / rung (time-source hierarchy) | **stratum / tier** (NTP) — the word "ladder" is the vector; rungs follow from it |
| door (an option or provision) | option, path, provision |
| adaptive avoidance, active set, scorecard | **adaptive frequency hopping (AFH)**, **channel map**, **channel classification / channel blacklisting** (Bluetooth, TSCH) |
| event chaining | **reference-broadcast synchronization** |
| rejoin window | **look-ahead window** (HOTP, RFC 4226) |
| deterministic alternation | **deterministic backoff** |

Not drift, keep as written: **supervision, supervised circuit, supervisory signal, "silence is the alarm"** — NFPA 72 fire-alarm terminology, and the Watchman thesis.
